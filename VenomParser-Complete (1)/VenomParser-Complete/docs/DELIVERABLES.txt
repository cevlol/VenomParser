💡 USAGE EXAMPLES
────────────────────────────────────────────────────────────────────────

Basic Usage:
```javascript
const parser = new AustralianBillParser();
const data = await parser.parsePDF(file);
console.log(data);
```

With Error Handling:
```javascript
try {
    const parser = new AustralianBillParser();
    const data = await parser.parsePDF(file);
    
    if (data._warnings) {
        console.warn('Some fields estimated:', data._warnings);
    }
    
    // Use the data
    updateCalculator(data);
} catch (error) {
    console.error('Parsing failed:', error);
    // Use fallback
    const fallback = AustralianBillParser.generateMockData();
    updateCalculator(fallback);
}
```
