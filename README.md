# VenomParser v11.3

![VenomProjects](assets/VenomProjectsBig.png)

**Australian Electricity Bill Parser for Solar Installers**

Automatically extract customer data from PDF electricity bills.

## Features
-  Extracts: Name, Address, NMI, Usage, Bill Amount
-  Supports 8+ Australian retailers
-  Auto-calculates solar recommendations
-  100% client-side (privacy-safe)
